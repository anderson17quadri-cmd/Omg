# Fora do Loop

Jogo de festa (single-device) empacotado como app Android via Capacitor.

## Gerar o APK

1. Crie um repositório novo no GitHub.
2. Suba todo este conteúdo para o repositório (branch `main`).
3. Vá em "Actions" no GitHub — o workflow "Build APK" roda sozinho.
4. Quando terminar (2-3 min), abra o run finalizado e baixe o artefato `fora-do-loop-apk` — é o .apk.
5. Transfira o .apk pro celular Android e instale (pode precisar permitir "instalar de fontes desconhecidas").

## Rodar localmente sem build
Basta abrir `www/index.html` em qualquer navegador.
